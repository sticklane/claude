  Edit pass that removes signs of AI-generated writing from EXISTING text.
  Use when asked to de-slop, humanize, clean up, or edit prose that is already
  drafted. Based on Wikipedia's comprehensive "Signs of AI writing" guide.
  Detects and fixes patterns including: inflated symbolism, promotional
  language, superficial -ing analyses, vague attributions, em dash overuse,
  rule of three, AI vocabulary words, passive voice, negative parallelisms,
  and filler phrases. Do NOT use while generating a first draft (use
  anti-ai-slop-writing), for checking claims against evidence (use
  grounding), or for reviewing this repo's own orientation docs (README,
  AGENTS.md, docs/, specs/ — /prose-review's rubric owns those).
